# Shubham Mohite — Portfolio

A premium, responsive developer portfolio built with **HTML, CSS and JavaScript**.

## Files
- `index.html` — complete portfolio structure/content
- `style.css` — responsive styling and animations
- `script.js` — cursor glow and reveal animations

## Customize before publishing
1. Replace project `href="#"` links with your live URLs.
2. Replace the GitHub/LinkedIn links with your profiles.
3. Add a profile photo if you want one.
4. Update project descriptions and skills as your stack grows.

## Run locally
Open `index.html` in a browser.

## Deploy
This folder can be deployed directly to Netlify, GitHub Pages, or any static hosting service.
